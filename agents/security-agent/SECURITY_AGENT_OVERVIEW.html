Section 01

How It Scans (Scanning Flow & Mechanics)

Phase 01
Detect & Scope

Discovers targets, resolves scan mode (Root, Domain Folder, Single File), and applies universal & domain rule packs across matching source files.

Phase 02
Context Analysis

Extracts a ±15 line radius around hits. Applies 8 conservative heuristics to eliminate false positives in __DEV__ blocks, comments, and types.

Phase 03
Heuristic Triage

Calculates a multi-factor risk score (0-100) based on Severity × Exploitability × Reachability × Impact to produce actionable priority buckets.

Phase 04
Report & Fix

Generates developer Markdown reports and machine-readable JSON for CI. Offers deterministic safe auto-fixes with atomic rollback.

NET-* / API-*
  • Cleartext HTTP (http://) and unencrypted WebSocket (ws://) URLs
  • Disabled SSL validation (rejectUnauthorized: false)
  • Network requests missing explicit timeouts / AbortController
  • Axios client instances missing enforced baseURL

LOG-001..004
  • Access tokens, refresh tokens & passwords passed to console.log
  • Sensitive user credentials printed via custom logging utilities

🗺️ Navigation & Deep Links
NAV-001..005
  • Unsanitized deep link URL parameters in Linking.addEventListener
  • Dynamic route injection vulnerabilities (navigation.navigate(variable))
  • Sensitive screens (payments, account) reachable without auth guards
  • Insecure custom URL schemes vs HTTPS Universal Links
 MASVS-CODE-4
🔐 Auth & Session Lifecycle
AUTH-* / SVC-*
  • Token refresh race conditions (missing concurrency mutex locks)
  • Single-use refresh token rotation verification
  • Hardcoded Authorization headers in API calls
  • Suspicious skipAuth: true bypass flags on endpoints
 MASVS-AUTH-1
🧩 Components & WebViews
CMP-* / SCR-*
  • WebView javaScriptEnabled with wildcard originWhitelist={['*']}
  • Dynamic eval() on WebView onMessage bridge payloads
  • Password / PIN TextInput fields missing secureTextEntry
  • Payment screens missing screenshot protection (FLAG_SECURE)
 MASVS-CODE-4
🛡️ Code Execution & XSS
GEN-001..008
  • Arbitrary code evaluation via eval() or Function()
  • Cross-site scripting via dangerouslySetInnerHTML
  • SQL injection risks via template literals in query builders
  • Cryptographically insecure randomness (Math.random() for tokens/IDs)
 MASVS-CODE-4
⚙️ Configuration & Env
CFG-* / ENV-*
  • Committed .env files containing sensitive production keys
  • Feature flags configured to bypass security controls in production
  • Inline SDK secrets (Firebase, Sentry DSN) inside shared config files
